# Notices and distribution boundary

Noiro Kodi is a client for sources the user is authorised to access. It does
not grant access rights, bypass DRM or determine whether a third-party source
is lawful in a user's jurisdiction.

The native engine is derived from the GPL-3.0 Noiro `stremiox-core` bridge and
the upstream Stremio core. Every distributed build must retain exact source and
dependency provenance. The local proprietary Stremio `server.js` used by some
Apple development builds is deliberately excluded.

Stremio, Kodi and OSMC are third-party projects and trademarks. Noiro Kodi is
not an official build of those projects.

`skin.noiro` includes the complete Estuary 4.0.0 window, font and texture base
shipped with Kodi 21.1 by OSMC for Vero 4K/4K+. Noiro's Home and video-library
windows are layered on that base so every standard Kodi and My OSMC window has
a safe implementation. Estuary's original `LICENSE.txt`, font notices and
corresponding assets are retained in the skin package. Estuary source:
https://github.com/xbmc/skin.estuary
